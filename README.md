# Rock-Paper-Scissors

じゃんけんしたい！！！  
ので、じゃんけんする　ぷろぐらむを　つくってくれるひと　ぼしゅうしています！

## 仕様

コンピューター相手にじゃんけん勝負を挑める。

### 必須要件

- ユーザーが「ぐー」「ちょき」「ぱー」のいずれかを選択もしくは入力できるようにしてください
- コンピューターには「ぐー」「ちょき」「ぱー」のいずれかをランダムに選択させてください
- 結果を判定し、ユーザーに表示してください

### 任意条件

- ユーザーが「ぐー」「ちょき」「ぱー」の出し方に迷わない感じになってると嬉しいな！
- ユーザーが勝ったときにはめっちゃ喜ばせるような演出があると嬉しいな！
